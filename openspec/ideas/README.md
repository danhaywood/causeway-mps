# OpenSpec ideas

This directory holds future-change notes that are not active OpenSpec changes.
Files here are intentionally outside `openspec/changes/`, so they do not weaken the repository rule that only one OpenSpec change may be active at a time.

An idea may contain motivation, preliminary scope, alternatives, risks, and unresolved questions.
It is not a validated specification, implementation commitment, or substitute for proposal, design, delta-spec, and task artifacts.

To promote an idea:

1. Complete or archive the current active change.
2. Review the idea against the then-current main specifications and implementation.
3. Create one active change with `openspec new change <name>`.
4. Use the idea as input while generating the normal OpenSpec artifacts.
5. Remove or replace the idea file once its useful content is captured by the active change.
